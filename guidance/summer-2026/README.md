# Summer 2026 Guidance

This folder contains guidance and supporting materials produced for the **Noteable® Summer 2026 update** and **Academic Year 2026–27**.

The materials cover updates to Noteable® environments and workflows, as well as guidance for staff and students using new or updated features.

## Contents

| Document | Description |
|---|---|
| **Noteable® Summer 2026 Environment and User Interface Updates** | Overview of updates to Noteable® notebook environments, core tools and the user interface. |
| **Noteable® Assignment Workflow Updates — Guidance for AY 2026–27** | Guidance on assignment-related workflows and changes relevant to teaching staff and students. |
| **Coding Agents in Noteable® — Guidance for AY 2026–27** | General guidance for institutions, staff and students on using Codex, Claude and OpenCode coding-agent tools in Noteable®. |
| **Using Coding Agents in Noteable® with ELM® API Keys** | University of Edinburgh-specific guidance on requesting and using ELM® API keys with compatible coding-agent workflows in Noteable®. |

## Intended use

These resources are intended to support:

- staff preparing teaching materials for Academic Year 2026–27;
- students using Noteable® in supported courses and activities;
- course organisers, teaching teams and local Noteable® administrators;
- users assessing whether updated Noteable® tools and workflows are suitable for their needs.

Please review the relevant guidance before using a new workflow in teaching or assessment.

## Important notes

- Notebook environments, packages and tools may be updated over time. For current information on available environments and selected installed tools, see the [Noteable® Notebook Descriptions page](https://noteable.edina.ac.uk/notebook-descriptions).
- Coding-agent tools may require users or institutions to arrange their own provider account, authentication, API access and credits. Any charges from an AI provider are separate from a Noteable® subscription.
- The ELM® API-key guidance is for **University of Edinburgh users only**. Other institutions should refer to the general coding-agents guidance and contact EDINA for further information about ELM®.
